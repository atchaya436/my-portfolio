# My Portfolio

My personal portfolio website — a single-page site showcasing my background, skills, projects, experience, and education as a Data Analyst and aspiring Data Scientist.

**Live site:** [atchaya436.github.io/my-portfolio](https://atchaya436.github.io/my-portfolio/)

## Overview

A responsive, single-page portfolio built to give a quick, complete picture of my work — from technical skills to project deep-dives — in one clean scroll, with light/dark theme support.

## Sections

- **About** — who I am and what I focus on
- **Skills** — a full stack view across the data lifecycle (analysis, ML, BI, tools)
- **Projects** — end-to-end builds with details on approach and impact
- **Experience** — where I've applied these skills in real internships
- **Education** — academic background
- **Certifications** — continuous learning
- **Contact** — how to reach me

## Features

- Responsive layout with a mobile navigation menu
- Light/dark theme toggle
- Smooth scroll navigation and a scroll-to-top control
- Single self-contained HTML file — fast to load, easy to deploy

## Tech Stack

`HTML` · `CSS` · `JavaScript`

## Running Locally

```bash
git clone https://github.com/atchaya436/my-portfolio.git
cd my-portfolio
```

Then just open `index.html` in your browser — no build step or dependencies required.

## Deployment

Hosted via GitHub Pages directly from this repo. Any changes pushed to `main` go live automatically.
